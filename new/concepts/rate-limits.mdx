There are three kinds of limits. All of them answer `429` when they are reached.

| Limit | Where it comes from | `code` of the 429 |
|---|---|---|
| Requests **per minute** of a key | Your plan, or the lower value you set on the key | `api_key_rate_limit_reached` |
| Requests **per month** of a key | Your plan, or the lower value you set on the key | `api_key_request_limit_reached` |
| **Searches** per month (and per minute) of your plan | Your plan | `subscription_search_limit_reached` |

Every search you make, from the API or from the app, counts towards the searches of your plan. Your plan's numbers are in **Current tenant settings > Subscription**.

## Headers

Every answer to a call with an API key carries your key's most pressing limit:

| Header | Meaning |
|---|---|
| `RateLimit-Limit` | Requests allowed in the current window. |
| `RateLimit-Remaining` | Requests left in the window. |
| `RateLimit-Reset` | Seconds until the window resets. |
| `RateLimit-Policy` | All the windows, for example `600;w=60`. |
| `Retry-After` | Only on `429`: seconds to wait before retrying. |

Use them to slow down **before** you hit the limit:

```python
r = requests.get(url, headers=headers)
if int(r.headers.get("RateLimit-Remaining", 1)) == 0:
    time.sleep(int(r.headers["RateLimit-Reset"]))
```

## Sizes and times

| What | Limit |
|---|---|
| File in `POST /storage/upload` | 50 MB. Bigger files go in parts: [Library](/new/guides/library). |
| Files in one `api/requests` call | 100 (`resource_ids`). |
| Results per search page | 200 (`limit`). |
| Wait of `POST /tools/{tool}` | 5000 ms by default; `timeout_ms` changes it. After that you get `202` and poll. |
| Idempotency keys | Remembered for 24 hours. |
| Trash | Files stay 30 days. |

## When you need more

Use a key per application and spread heavy work (a big batch of photos) over time. For higher limits, contact your Wesog representative.
