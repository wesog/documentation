**Base address:** `https://api.wesog.com/api/v1`

**Authentication:** the `X-API-Key` header on every call. See [Authentication](/new/concepts/authentication).

**Errors:** the same body everywhere: `code`, `message`, `request_id`. See [Errors](/new/concepts/errors).

Each operation page shows:

- what it does and which **key scope** opens it;
- the request and response with **examples** you can copy and the typed fields;
- the **errors** it can answer;
- ready-to-run samples in **cURL, Python and JavaScript**.

Press **Try it** on any operation, paste your API key and call it from the page.

The same reference, always up to date, is served as an OpenAPI document at `https://api.wesog.com/api/openapi-customer.json?server=public`: import it into Postman, Insomnia or a code generator.

New to the API? Start with the [Quickstart](/new/quickstart).
