You need a Wesog account. Everything below uses the base address `https://api.wesog.com/api/v1`.

## 1. Create an API key

In Wesog open **Current tenant settings > General > API keys** and press **New key**. Give it a name and, if you want, limit what it can do (see [Authentication](/new/concepts/authentication)). Copy the key: **it is shown only once**.

Keep it in an environment variable. Never put it in a web page or a public repository.

```bash
export WESOG_API_KEY="paste-your-key-here"
```

## 2. Check that it works

<CodeGroup>
```bash cURL
curl 'https://api.wesog.com/api/v1/tools?limit=5' \
  -H "X-API-Key: $WESOG_API_KEY"
```

```python Python
import os, requests

headers = {"X-API-Key": os.environ["WESOG_API_KEY"]}
r = requests.get("https://api.wesog.com/api/v1/tools", headers=headers, params={"limit": 5})
r.raise_for_status()
print([t["slug"] for t in r.json()["items"]])
```

```javascript JavaScript
const headers = { "X-API-Key": process.env.WESOG_API_KEY };
const r = await fetch("https://api.wesog.com/api/v1/tools?limit=5", { headers });
if (!r.ok) throw new Error(await r.text());
console.log((await r.json()).items.map((t) => t.slug));
```
</CodeGroup>

You get the list of tools your plan includes (`caption`, `ocr`, `image_tag`...). If you get `401`, the key is wrong or missing; if you get `403`, the key has scopes that do not cover this call.

## 3. Tag your first photo

<CodeGroup>
```bash cURL
curl -X POST 'https://api.wesog.com/api/v1/tools/caption' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"image_url": "https://example.com/photos/runway.jpg", "lang": "en"}'
```

```python Python
r = requests.post(
    "https://api.wesog.com/api/v1/tools/caption",
    headers=headers,
    json={"image_url": "https://example.com/photos/runway.jpg", "lang": "en"},
)
print(r.status_code, r.json())
```

```javascript JavaScript
const r = await fetch("https://api.wesog.com/api/v1/tools/caption", {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({ image_url: "https://example.com/photos/runway.jpg", lang: "en" }),
});
console.log(r.status, await r.json());
```
</CodeGroup>

Status `200` carries the result. Status `202` means it is still running: read [Async and polling](/new/concepts/async). To send a file instead of an address, use `multipart/form-data` with the field `image`. All the tools are in [Tag photos](/new/guides/tag-photos).

## 4. Upload a photo and search for it

Upload (files up to 50 MB; bigger ones go in parts, see [Library](/new/guides/library)):

```bash
curl -X POST 'https://api.wesog.com/api/v1/storage/upload' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Idempotency-Key: 6f1c2a9e-0000-4000-8000-000000000001' \
  -F 'file=@runway.jpg' \
  -F 'relative_path=events/2026/runway.jpg'
```

The photo is indexed within minutes. Then search in plain language:

<CodeGroup>
```bash cURL
curl -X POST 'https://api.wesog.com/api/v1/library/search' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"query": "model walking the runway", "limit": 10}'
```

```python Python
r = requests.post(
    "https://api.wesog.com/api/v1/library/search",
    headers=headers,
    json={"query": "model walking the runway", "limit": 10},
)
for item in r.json()["items"]:
    print(item["resource_id"], item["title"])
```

```javascript JavaScript
const r = await fetch("https://api.wesog.com/api/v1/library/search", {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json" },
  body: JSON.stringify({ query: "model walking the runway", limit: 10 }),
});
for (const item of (await r.json()).items) console.log(item.resource_id, item.title);
```
</CodeGroup>

More in [Search](/new/guides/search).

## 5. Run your first workflow from your program

A workflow can take its files from the API. Find yours and send it photos of your Library:

```bash
# which launched workflows do I have?
curl 'https://api.wesog.com/api/v1/workflow-instances' -H "X-API-Key: $WESOG_API_KEY"

# send two photos (their resource_id) to the workflow
curl -X POST 'https://api.wesog.com/api/v1/workflow-instances/INSTANCE_ID/api/requests' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: 6f1c2a9e-0000-4000-8000-000000000002' \
  -d '{"resource_ids": [1048223, 1048224]}'
```

You get `202` and one `request_id` per photo. Read each result as it finishes: [Run a workflow](/new/guides/run-workflow).
