`POST /library/search` finds photos, videos and documents of your organization from a sentence. You do not build filters: you say what you want.

<CodeGroup>
```bash cURL
curl -X POST 'https://api.wesog.com/api/v1/library/search' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"query": "Rafael Nadal celebrating a point in Madrid", "resource_types": ["image"], "limit": 20}'
```

```python Python
import os, requests

r = requests.post(
    "https://api.wesog.com/api/v1/library/search",
    headers={"X-API-Key": os.environ["WESOG_API_KEY"]},
    json={"query": "Rafael Nadal celebrating a point in Madrid", "resource_types": ["image"], "limit": 20},
)
r.raise_for_status()
page = r.json()
print(page["total"], "results")
for item in page["items"]:
    print(item["resource_id"], item["title"], item["thumbnail_url"])
```

```javascript JavaScript
const r = await fetch("https://api.wesog.com/api/v1/library/search", {
  method: "POST",
  headers: { "X-API-Key": process.env.WESOG_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({ query: "Rafael Nadal celebrating a point in Madrid", resource_types: ["image"], limit: 20 }),
});
const page = await r.json();
console.log(page.total, "results");
for (const item of page.items) console.log(item.resource_id, item.title, item.thumbnail_url);
```

## What you can ask

The `query` understands people, places, dates, what is in the image and the type of file: *"Pedro Sánchez smiling at a rally in 2024"*, *"beach at sunset"*, *"videos of the final"*. An empty `query` lists the Library, newest first (change the order with `sort`).

| Field | Meaning |
|---|---|
| `query` | What you look for, in your language. |
| `resource_types` | `image`, `video`, `document`, `audio`. Empty means all. |
| `limit`, `offset` | Page size (1-200) and where to start. See [Pagination](/new/concepts/pagination). |
| `sort` | Only with an empty `query`: `updated_desc`, `updated_asc`, `created_desc`, `name_asc`, `name_desc`. |
| `filters` | Extra conditions, for example a date range of the creation date. |

A date range:

```json
{
  "query": "fashion week",
  "filters": { "field_filters": [ { "field": "created_at", "op": "between", "value": { "from": "2026-09-01", "to": "2026-09-30" } } ] }
}
```

## What you get

```json
{
  "total": 128,
  "total_is_estimated": false,
  "next_offset": 20,
  "items": [
    {
      "resource_id": "1048223",
      "resource_type": "image",
      "title": "Nadal celebrates a point",
      "snippet": "Rafael Nadal celebrates a point during the final in Madrid.",
      "thumbnail_url": "https://api.wesog.com/api/v1/search/resources/acme/images/1048223/media",
      "own_tenant": true,
      "metadata": { "field_values": { "headline": "Nadal celebrates a point", "city": "Madrid" } }
    }
  ]
}
```

Results come best first. `metadata.field_values` holds the descriptive data (headline, caption, keywords, author, place, dates) and `metadata.detected_identities` the people recognised. Use `resource_id` to [open, edit or delete](/new/guides/library) the file.

## Open one result

`GET /library/tables/{source_table}/rows/{row_id}` returns all the stored data of a file. Use the `fields` parameter to ask only for what you need.

## Conversational search

If you build a chat on your own website, the **conversational search** keeps the context ("now only the videos") and asks when a request is ambiguous. It is a different API: [Conversational search](/new/platform-api/conversational-search).

## Good to know

- Each search counts towards your plan's searches. See [Limits](/new/concepts/rate-limits).
- A file you just uploaded can take a few minutes to be searchable.
- Searching with an API key reaches your organization's Library. Archives other organizations share with you appear with `own_tenant: false`.
