Si tu llamada agota el tiempo de espera, no sabes si el archivo llegó a subirse o si el workflow llegó a lanzarse. Si la repites, podría ocurrir dos veces.

Envía una cabecera `Idempotency-Key` con un valor que elijas (un UUID) en las operaciones que crean o lanzan algo. Si repites la llamada con **la misma clave**, recibes **la primera respuesta otra vez** en lugar de ejecutarla de nuevo. La respuesta repetida lleva `Idempotent-Replayed: true`.

```bash
curl -X POST 'https://api.wesog.com/api/v1/workflow-instances/INSTANCE_ID/api/requests' \
  -H "X-API-Key: $WESOG_API_KEY" \
  -H 'Idempotency-Key: 6f1c2a9e-0000-4000-8000-000000000002' \
  -H 'Content-Type: application/json' \
  -d '{"resource_ids": [1048223]}'
```

## Dónde funciona

En las operaciones marcadas con el parámetro `Idempotency-Key` en la [referencia de la API](/es/new/openapi/introduction): ejecutar una herramienta, subir un archivo (incluidos los pasos de subida grande), crear una carpeta y enviar archivos a un workflow. En el resto, la cabecera se ignora.

## Reglas

- La clave tiene de 1 a 128 caracteres: letras, dígitos, `-`, `_`, `:` y `.`.
- Se recuerda durante **24 horas**, por clave API, método y ruta.
- Misma clave y **mismo** cuerpo: la primera respuesta otra vez, sin ejecutar nada.
- Misma clave y un cuerpo **distinto**: `409` `idempotency_key_reuse`. Una clave identifica una operación; usa una clave nueva para una operación nueva.
- Misma clave mientras la primera llamada **sigue ejecutándose**: `409` `idempotency_key_in_use` con `Retry-After`. Espera y repite.
- Solo se recuerdan las respuestas **correctas**. Si la primera llamada falló (`4xx`, `429`, `5xx`), puedes repetirla con la misma clave y se ejecutará.

## Un buen patrón

Crea la clave cuando decidas hacer la operación (guárdala junto con tu tarea) y úsala en todos los reintentos de esa tarea.

<CodeGroup>
```python Python
import os, uuid, requests

BASE = "https://api.wesog.com/api/v1"
headers = {"X-API-Key": os.environ["WESOG_API_KEY"]}

key = str(uuid.uuid4())          # una por tarea, se conserva para sus reintentos
r = requests.post(f"{BASE}/storage/folders", headers={**headers, "Idempotency-Key": key},
                  json={"relative_path": "events/2027"})
```

```javascript JavaScript
const BASE = "https://api.wesog.com/api/v1";
const headers = { "X-API-Key": process.env.WESOG_API_KEY };
const key = crypto.randomUUID(); // una por tarea, se conserva para sus reintentos
const r = await fetch(`${BASE}/storage/folders`, {
  method: "POST",
  headers: { ...headers, "Content-Type": "application/json", "Idempotency-Key": key },
  body: JSON.stringify({ relative_path: "events/2027" }),
});
```
